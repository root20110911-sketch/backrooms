玩法说明

目标

从 Level 0 出发，逐层切出，最终逃离后室。主线：L0 → L1 → L2 → L3 → 结局。

操作

桌面：键位总览见下表。

移动WASD（方向键亦可）
视角鼠标（点击画面锁定）
疾跑Shift
蹲伏C 或 左 Ctrl
交互E
手电筒F
物品 1–51杏仁水 2绷带 3手电 4迁跃浆果 5食物
暂停Esc

手机/平板：左侧摇杆移动 · 右侧拖动视角 · 准星按钮交互
建议横屏 + 全屏游玩，视野更宽。

生存

留意声音和灯光。奔跑会引来注意，蹲下贴墙更安全。杏仁水回血，绷带治伤。

理智

血条下方的紫色是理智值。黑暗、断电和实体会侵蚀理智；理智过低会出现幻听、视线晃动，还更容易被实体发现。杏仁水恢复 30 点理智，安全屋能缓慢恢复。

马尼拉房间

Level 0 里有一间暖黄色的安全屋——地毯、补给箱和字条。在里面待着可以回理智，是整层唯一安全的地方。

薄墙切出

有些墙"薄得不对劲"。贴着它持续往里挤约 1.4 秒，你会被随机甩到本层的另一个角落（-12 理智）。这是条野路子，但落点不保证安全。
