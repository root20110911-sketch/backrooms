# Backrooms：切出

一款以后室（Backrooms）为题材的**第一人称 3D 浏览器游戏**：探索、生存、切出。

- 十四个可玩关卡：Level 0（教学）→ Level 1（宜居地带）→ Level 2（废弃公共带）→ Level 3（发电站）→ 完整结局，外加隐藏支线 Level Fun（享乐层 =)）
- 扩建关卡：Level 188（百窗庭，观察窗户与收音机找路）/ Level 37（泳池房，深浅水区藏着出口）/ Level 37.2（阳光泳池，天空之境改编）/ Level 7（深海恐惧症，四水层 + 七层之物）/ Level 11（无垠城市，M.E.G. 前哨与流浪者营地的枢纽）/ Level !（不想死就快跑！，医院追逐走廊）/ Level 4（废弃办公室）/ Level 6（熄灯之时）/ Level 25（街机枢纽）
- Level 94「动画」已于 v1.5 退役（内容被 Level ! 替换，老存档自动迁移）
- 随机种子生成地图：同一种子同一关卡完全一致，不同种子房间/走廊/道具/事件位置明显不同
- 实体 AI：猎犬、潜伏者、派对客、七层之物等，各有不同的感知与行为
- 切出过场动画、死亡重试、检查点、本地存档继续（按关卡持久化）
- 桌面（WASD+鼠标）与平板/手机（浮动摇杆+拖动视角）双操作，支持双指同屏

## 运行

纯静态页面，无需构建，直接用任意静态服务器打开：

```bash
cd backrooms
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080/index.html
```

也可以把整个目录丢到任何静态托管（GitHub Pages / Netlify / Cloudflare Pages 等）直接发布。

### 操作

| 桌面 | 平板/手机 |
|---|---|
| WASD / 方向键 移动，鼠标视角 | 左侧浮动摇杆移动，右侧拖动视角 |
| E / 鼠标左键 交互，F 手电 | ✋ 交互大钮（有目标时高亮，无目标置灰），右上 🔦 手电（mini 系统区） |
| Shift 跑，C 蹲/下潜，空格 跳/上浮 | 右上 mini 区：⏸ 暂停 / 🎒 背包 / 🔦 手电 / 🏃 疾跑（开关式）/ 视角；右下：⬇ 蹲（仅陆地），下坐骑（仅坐骑），跳跃/下潜簇（仅水中显下潜，坐骑时隐藏） |
| Tab / I 背包，V 第三人称 | 🎒 背包（触屏标题适配），视角切换 mini 按钮 |
| Esc 暂停 | 右上 mini 区 ⏸ 暂停 |

使用物品统一走**背包**：打开背包后单击道具直接使用（吃/喝/装备/部署），空背包显示空白面板。左下角快捷物品栏已于 v1.5.1 移除。

暂停菜单可调：视角灵敏度、音量、镜头晃动、减镜头震动、**坠落镜头（完整/柔和/关闭）**、低理智特效、摇杆大小/左右位置、画质，自动保存在本地。所有设置项均真实生效。

- **坠落镜头**：切出/坠落演出的镜头强度。"完整"是默认的强烈第一人称坠落镜头（含翻滚与视场角变化）；"柔和"幅度减半、无翻转；"关闭"用淡入淡出代替。若感到晕眩，建议切到"柔和"或"关闭"。

### 物品与新机制

- **迁跃浆果**：稀有消耗品，板条箱（2%）/ M.E.G. 赠送获得。吃下去会**随机传送到未知层级——目标随机，可能更危险，不是安全回城**。在背包里单击食用即传送，无二次确认，请三思。
- **随机裂隙/地洞**：各关极低概率显形（显形前 3~5 秒有视听征兆，如墙角裂缝、地板洞、回头变的门）。可主动进入，也可能一脚踩空；目的地从十四关里按权重随机（排除当前关），同一种子同事件次数落点相同。落地后有 3 秒恢复。裂隙是"被空间吸入"的感觉，不是稳定路线——别指望它。
- **七色滑梯**（Level Fun 派对区深处）：7 条滑梯，颜色**固定通往**一个层级（红→L0 / 橙→L37 / 黄→L11 / 绿→L1 / 青→L7 / 蓝→Level ! / 紫→L188），梯口各有线索（海报、水渍、明信片、荧光标记、贝壳、"跑"字涂鸦、窗框碎片）。注意**蓝色滑梯落点是 Level !「不想死就快跑！」的医院长廊**，危险落点，看好再滑（已逃脱过则重抽其他层级）。
- **FUN 涂鸦洞口**：L0 约 8% 的地图会在角落生成派对客笑脸涂鸦，附近洞口可直接爬进 Level Fun（与 L1 天花板破洞路线并存）。
- **通风管（固定映射切出，v2.2）**：L0/L1/L2 各有 2 根墙面通风管，钻进去**只去固定层级、只认边框颜色不认位置**——| 起点 | 去向 | 边框色 |
  |---|---|---|
  | Level 0 | Level 1「宜居地带」 | 绿色 |
  | Level 1 | Level 2「废弃公共带」 | 琥珀色 |
  | Level 2 | Level 3「发电站」 | 蓝色 |
  第一根管子旁贴着一张 \"M.E.G. 通风管路图\" 字条写着对照表，可学会、可重复阅读；交互提示即显示目的地（无随机、无代价、与薄墙野生切出 -12 理智区分）。纯游戏机制，原著没有通风管固定路线的设定。
- **门按关卡风格（v2.2）**：9 种门风格与关卡气氛匹配——L0 黄木门 / L1 混凝土 / L2 管道金属 / L188 深色雕花 / L4 玻璃门 / L37 白瓷推拉门 / L6 钢门 / FUN 派对红 / L3 锈蚀金属。纯视觉/交互还原，无 lore 依据，LORE.md 标注为游戏改编。
- **容器逐件拾取**：柜子/箱子/抽屉可打开，看到内部真实物品后逐件拾取（准星对准+交互），已开容器与已取物品进存档。
- **开发者模式**：暂停菜单底部「开发者选项」，密码 `muse`。作弊开关**三独立项**——无限体力/无限理智/无限生命（开启瞬间数值直接锁到 **999**，`player.js` 每帧末尾重新 pin 住 999：任何扣减路径，包括直接扣血/扣理智的暗器/腰果水/饥饿惩罚，都会在帧末被纠正；理智 999 时低理智特效不触发）、**14 关传送表**（L0/L1/L2/L3/L4/L6/L7/L11/L25/L37/L37.2/L188/Level!/FUN 落点全部验证安全）、回满状态。作弊开关状态经 `localStorage`（`br_dev_*`）持久化，刷新页面后仍然保持；刷新后需重新输密码进入开发者面板（会话级）。

### 世界种子

标题界面显示当前种子；输入框可填入任意数字种子开局。相同种子 → 相同地图。

### 模块加载顺序

`three.min.js(CDN) → config → utils → items → textures → audio → gen → gen_l4/gen_l188/gen_l37/gen_l372/gen_l7/gen_l11/gen_l25/gen_bang/gen_l6 → world → player → input → entities → transitions → cutout → levels → levels2 → lv_l4/lv_l188/lv_l37/lv_l372/lv_l7/lv_l11/lv_l25/lv_bang/lv_l6 → sanityEvents → ui → dev → save → main`

所有模块挂在 `window.BR` 下；`main.js` 在 `DOMContentLoaded` 后初始化。新增关卡的 script 标签按"gen_l* 在 gen.js 后、lv_l* 在 levels.js/levels2.js 后"的顺序加载（index.html 里已配好）。

## 存档

进度保存在浏览器 `localStorage`（`backrooms_save_v2`，v1 旧 key 只读迁移）：种子、关卡、位置、血量/理智/饥饿、物品、按关卡的已开门/箱子/已拾取/事件。标题界面提供「继续游戏」。跨关保持角色资源连续性（不重置）。通关后存档清除。

## 性能

- 区块流式加载：只完整构建玩家附近区块，远处卸载并释放资源
- 点光源池化（按画质 3–7 个），灯光按距离分配
- 远处实体降频 AI（>48 米跳过，>60 米隐藏）
- 单帧建块预算 10ms，跨区块移动无明显卡顿

## 设定说明

本作基于后室中文维基（backrooms-wiki-cn.wikidot.com）的 Level 0–3 与 Level Fun、Entity 67（派对客）设定改编；扩建关卡以 Fandom Backrooms Wiki 的 Level 37（泳池房）、Level 188 "The Windows"（酒店版）、Level 7（深海恐惧症）、Level 11（无垠城市）、Level !（医院走廊）、Level 25（街机枢纽）等为原型，Level 4 / Level 6 以 Wikidot 版为基调。
其中「Level Fun 可凭两条线索经员工通道离开」「七色滑梯」「随机裂隙」「迁跃浆果」「各新增关的出口」「L0 主出口金属门」「L0 无限延伸」均为**游戏性改编**（原作 Fun 没有可靠出口、Object 74 并非随机传送），游戏内与 LORE.md 均有明确标注。
v2.1 新增 Level 37.2「Sunlit Pools（阳光泳池）」为**改编关**：原型是 Fandom Backrooms Wiki 的 Level 37.2 "Sunlit Pools" 条目（粉色开口光 + Pinnicorns 充气浮具实体），但本作的**露天蓝天、可见太阳、天空之境倒影是明确的游戏改编**（原著只有墙面矩形开口透出的粉色光，开口之外是白色虚空），文档与 LORE.md 均标注为改编，不伪装成"还原原著"。详见 `LORE.md`。
