# Backrooms：切出

一款以后室（Backrooms）为题材的**第一人称 3D 浏览器游戏**：探索、生存、切出。

- 十个可玩关卡：Level 0（教学）→ Level 1（宜居地带）→ Level 2（废弃公共带）→ Level 3（发电站）→ 完整结局，外加隐藏支线 Level Fun（享乐层 =)）
- 新增五关：Level 188（百窗庭，观察窗户与收音机找路）/ Level 37（泳池房，深浅水区藏着出口）/ Level 94（动画，昼夜循环的定格动画小镇）/ Level 7（深海恐惧症，利维坦游荡的昏暗海洋）/ Level 11（无垠城市，M.E.G. 前哨与流浪者营地的枢纽）
- 随机种子生成地图：同一种子同一关卡完全一致，不同种子房间/走廊/道具/事件位置明显不同
- 实体 AI：猎犬、潜伏者、派对客，各有不同的感知与行为
- 切出过场动画、死亡重试、检查点、本地存档继续
- 桌面（WASD+鼠标）与平板/手机（浮动摇杆+拖动视角）双操作，支持双指同屏

## 运行

纯静态页面，无需构建，直接用任意静态服务器打开：

```bash
cd backrooms
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080/index.html
```

也可以把整个目录丢到任何静态托管（GitHub Pages / Netlify / Cloudflare Pages 等）直接发布。

### 操作

| 桌面 | 平板/手机 |
|---|---|
| WASD / 方向键 移动，鼠标视角 | 左侧浮动摇杆移动，右侧拖动视角 |
| E 交互，F 手电 | ✋ 交互，🔦 手电 |
| Shift 跑，C / 左 Ctrl 蹲 | 🏃 跑，⬇ 蹲 |
| 1/2/3/4 使用物品（4 = 迁跃浆果） | 点物品栏使用 |
| Esc 暂停 | 右上角 ⏸ 暂停 |

暂停菜单可调：视角灵敏度、音量、**坠落镜头（完整/柔和/关闭）**、摇杆大小/左右位置、画质，自动保存在本地。

- **坠落镜头**：切出/坠落演出的镜头强度。"完整"是默认的强烈第一人称坠落镜头（含翻滚与视场角变化）；"柔和"幅度减半、无翻转；"关闭"用淡入淡出代替。若感到晕眩，建议切到"柔和"或"关闭"。

### 物品与新机制

- **迁跃浆果**（`Digit4`）：稀有消耗品，板条箱（2%）/ M.E.G. 赠送获得。吃下去会**随机传送到未知层级——目标随机，可能更危险，不是安全回城**。食用即传送，无二次确认，请三思。
- **随机裂隙/地洞**：各关极低概率显形（显形前 3~5 秒有视听征兆，如墙角裂缝、地板洞、回头变的门）。可主动进入，也可能一脚踩空；目的地从十关里按权重随机（不排除 FUN，但排除当前关），同一种子同事件次数落点相同。落地后有 3 秒恢复。裂隙是"被空间吸入"的感觉，不是稳定路线——别指望它。
- **七色滑梯**（Level Fun 派对区深处）：7 条滑梯，颜色**固定通往**一个层级（红→L0 / 橙→L37 / 黄→L11 / 绿→L1 / 青→L7 / 蓝→Level ! / 紫→L188），梯口各有线索（海报、水渍、明信片、荧光标记、贝壳、"跑"字涂鸦、窗框碎片）。注意**蓝色滑梯落点是 Level !「不想死就快跑！」的医院长廊**，危险落点，看好再滑（已逃脱过则重抽其他层级）。
- **FUN 涂鸦洞口**：L0 约 8% 的地图会在角落生成派对客笑脸涂鸦，附近洞口可直接爬进 Level Fun（与 L1 天花板破洞路线并存）。

### 世界种子

标题界面显示当前种子；输入框可填入任意数字种子开局。相同种子 → 相同地图。

## 工程结构

```
index.html            页面与全部 UI 结构
css/style.css         样式（含触控 HUD、横竖屏适配）
js/
  vendor/three.min.js Three.js r128（MIT，随附本地）
  config.js           全局命名空间、常量、事件总线
  utils.js            RNG（mulberry32）、种子哈希、数学/几何工具
  textures.js         程序化 Canvas 纹理（墙纸/地毯/混凝土/砖/派对…）
  audio.js            WebAudio 合成音效与环境声（无外部音频文件）
  gen.js              随机地图生成器（房间/走廊/POI/连通性保证）
  world.js            场景、区块流式加载/卸载、碰撞、门、交互、灯光
  player.js           第一人称控制器（移动/跑/蹲/血量/手电/噪音）
  input.js            键鼠 + 触控（浮动摇杆/双指）+ 设置持久化
  entities.js         实体 AI（猎犬/潜伏者/派对客）+ 程序化模型
  transitions.js      切出过场（黑屏字幕/镜头动画/看门狗）
  cutout.js           统一切出状态机（抵达演出/坠落镜头设置）+ 随机裂隙 + 七色滑梯映射
  levels.js           旧五关主题、道具、事件、目标（+ FUN 七色滑梯区）
  gen_l188.js         L188 地图生成器（中庭/走廊/客房/窗）
  gen_l37.js          L37 地图生成器（深水/浅水池区）
  gen_l94.js          L94 地图生成器（小镇/城堡/藏身点）
  gen_l7.js           L7 地图生成器（海洋/浅滩/动静点/入口房）
  gen_l11.js          L11 地图生成器（街区/MEG 前哨/营地/地铁站）
  lv_l188.js          L188 主题、道具、事件、目标
  lv_l37.js           L37 主题、道具、事件、目标（+ BR.Swim 游泳共享模块）
  lv_l94.js           L94 主题、道具、事件、目标（+ 昼夜系统）
  lv_l7.js            L7 主题、道具、事件、目标
  lv_l11.js           L11 主题、道具、事件、目标（+ NPC 对话）
  ui.js               标题/HUD/暂停/笔记/死亡/结局/调试面板（物品：杏仁水/绷带/手电/迁跃浆果）
  save.js             localStorage 存档（种子/关卡/位置/拾取/门/事件）
  main.js             游戏主流程与主循环
LORE.md               设定考据：十个层级 + 派对客 + 随机裂隙/迁跃浆果/滑梯机制，原作 vs 游戏改编逐项标注
SPEC.md               模块接口与系统规格
ASSETS.md             素材来源与授权说明
tools/e2e/            自动化测试（puppeteer + 截图）
```

### 模块加载顺序

`three.min.js → config → utils → textures → audio → gen → gen_l188/l37/l94/l7/l11 → world → player → input → entities → transitions → cutout → levels → lv_l188/l37/l94/l7/l11 → ui → save → main`

所有模块挂在 `window.BR` 下；`main.js` 在 `DOMContentLoaded` 后初始化。新增关卡的 script 标签按"gen_l* 在 gen.js 后、lv_l* 在 levels.js 后"的顺序加载（index.html 里已配好）。

## 存档

进度保存在浏览器 `localStorage`（`backrooms_save_v1`）：种子、关卡、位置、血量、物品、已开的门/箱子/事件。标题界面提供「继续游戏」。通关后存档清除。

## 性能

- 区块流式加载：只完整构建玩家附近区块，远处卸载并释放资源
- 点光源池化（按画质 3–7 个），灯光按距离分配
- 远处实体降频 AI（>48 米跳过，>60 米隐藏）
- 单帧建块预算 10ms，跨区块移动无明显卡顿

## 设定说明

本作基于后室中文维基（backrooms-wiki-cn.wikidot.com）的 Level 0–3 与 Level Fun、Entity 67（派对客）设定改编；新增五关以 Fandom Backrooms Wiki 的 Level 37（泳池房）、Level 188 "The Windows"（酒店版）等为原型。
其中「Level Fun 可凭两条线索经员工通道离开」「七色滑梯」「随机裂隙」「迁跃浆果」「各新增关的出口」均为**游戏性改编**（原作 Fun 没有可靠出口、Object 74 并非随机传送），游戏内与 LORE.md 均有明确标注。详见 `LORE.md`。
